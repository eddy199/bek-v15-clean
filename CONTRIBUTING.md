# 🤝 Contribuer à BEK Hybrid Agent

Merci de ton intérêt pour BEK ! Ce guide t'explique comment contribuer efficacement.

---

## 📋 Code de conduite

- Sois respectueux et bienveillant.
- Pas de langage offensant, discriminatoire ou harcelant.
- Les désaccords techniques sont OK, les attaques personnelles non.

---

## 🐛 Signaler un bug

1. Vérifie que le bug n'a pas déjà été signalé dans les [Issues](https://github.com/eddy199/bek-hybrid-agent/issues).
2. Crée une nouvelle issue avec :
   - **Titre clair** : "MCP ne détecte pas les outils sur Windows 11"
   - **Description** : ce que tu as fait, ce que tu attendais, ce qui s'est passé
   - **Logs** : extrait du terminal (⚠️ supprime les clés API avant de coller)
   - **Environnement** : OS, version Python, version BEK

---

## 💡 Proposer une fonctionnalité

1. Ouvre une issue avec le tag `[Feature Request]`.
2. Décris :
   - **Le problème** que tu veux résoudre
   - **La solution** que tu proposes
   - **Les alternatives** que tu as considérées
