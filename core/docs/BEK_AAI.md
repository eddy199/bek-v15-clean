# BEK-AAI — Agent-as-an-Instruction
## Un agent entier devient une instruction

**Version :** 1.0
**Date :** 2026-09-23
**Brevet :** BEK-AAI-v1.0

---

## 1. PRINCIPE

**Un agent IA complet (500 fichiers, 50 000 lignes) devient UNE abréviation.**

**Exemple :**
- Agent BEK v18 = 500 fichiers
- Devient : `BEK-AGENT-v18`
- Appelable : `BekCPU.execute("BEK-AGENT-v18", "chat", query="...")`

**Résultat :** un agent peut être **appelé comme une fonction**.
