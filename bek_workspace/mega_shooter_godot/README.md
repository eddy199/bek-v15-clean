# Mega Shooter Godot

Projet de jeu de tir (shooter) développé avec le moteur Godot.

## Dépendances

- Godot Engine (version 4.x recommandée)
- Aucun plugin externe requis

## Instructions de lancement

1. Cloner ce dépôt
2. Ouvrir Godot
3. Cliquer sur "Importer" et sélectionner le dossier du projet
4. Lancer la scène principale (`res://scenes/main.tscn` ou `res://main.tscn`)

## Structure

- `scenes/` : Scènes Godot (.tscn)
- `scripts/` : Scripts GDScript (.gd)
- `assets/` : Ressources (images, sons, polices)
